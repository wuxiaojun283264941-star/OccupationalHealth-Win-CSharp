 客户端使用说明
═══════════════════════════════════════

1. 启动客户端
   双击 "启动客户端.bat"，会自动打开浏览器
   访问已配置的服务器地址

2. 配置服务器地址
   打开 "服务器配置.txt" 修改即可：
   ┌─────────────────────────────────┐
   │ IP地址=192.168.1.100           │  ← 改为服务器实际IP
   │ 端口=3001                      │  ← 默认3001
   │ 协议=http                      │  ← 不用改
   └─────────────────────────────────┘

3. 部署场景

   场景A: 单机使用
   ┌─────────────────────────────────┐
   │ 客户端和服务器装在同一台电脑    │
   │ → 服务器配置.txt 保持默认      │
   │    IP地址=localhost             │
   └─────────────────────────────────┘

   场景B: 局域网部署
   ┌─────────────────────────────────┐
   │ 一台服务器 + 多台客户端         │
   │ → 服务器端电脑运行 Server.exe   │
   │ → 客户端电脑修改配置:           │
   │    IP地址=服务器电脑的内网IP     │
   │    如: IP地址=192.168.1.100     │
   └─────────────────────────────────┘

   场景C: 公网部署
   ┌─────────────────────────────────┐
   │ → 服务器部署到云服务器          │
   │ → 客户端电脑修改配置:           │
   │    IP地址=公网IP或域名           │
   │    如: IP地址=www.example.com   │
   └─────────────────────────────────┘

4. 常见问题
   Q: 浏览器打开后显示"无法访问此网站"
   A: 检查服务器是否已启动，IP和端口是否正确

   Q: 启动客户端.bat 一闪而过
   A: 双击是正常的，它会自动打开浏览器
      如果浏览器没出来，手动打开浏览器输入地址

   Q: 提示"端口被占用"
   A: 打开服务器端 appsettings.json
      修改端口号后重新启动 Server.exe
      同时将客户端的端口改为一致
