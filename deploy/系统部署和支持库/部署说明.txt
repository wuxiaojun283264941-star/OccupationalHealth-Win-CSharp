 系统部署说明
═══════════════════════════════════════

一、服务器端部署

1) 将发布包复制到服务器
   确保以下文件齐全：
   服务器端\
   ├── Server.exe          ← 主程序
   ├── *.dll               ← 所有依赖库
   ├── appsettings.json    ← 服务器配置
   ├── web.config          ← IIS配置(如有)
   └── wwwroot\            ← 前端页面

2) 启动服务器
   双击 Server.exe 即可
   首次启动会自动：
   ✓ 创建 SQLite 数据库
   ✓ 导入种子数据
   ✓ 创建桌面快捷方式
   ✓ 创建上传目录

3) 配置服务器（可选）
   编辑 appsettings.json:
   {
     "Jwt": {
       "Secret": "可选修改JWT密钥",
       "ExpiresInHours": 24
     },
     "UploadSettings": {
       "MaxFileSize": 20971520,
       "UploadDir": "uploads/reports"
     }
   }

4) 修改端口（可选）
   命令行：set PORT=8080 && Server.exe
   或修改 appsettings.json 中相关配置

二、客户端部署

1) 将 客户端\ 文件夹分发给各用户
   客户端\
   ├── 启动客户端.bat      ← 双击启动
   ├── 服务器配置.txt       ← 编辑服务器地址
   └── 客户端使用说明.txt   ← 使用说明

2) 配置服务器地址
   编辑 服务器配置.txt:
   IP地址=192.168.1.100    ← 改为实际服务器IP
   端口=3001
   协议=http

3) 启动
   双击 启动客户端.bat → 自动打开浏览器访问服务器

三、系统要求

操作系统：Windows 10 / 11 (64位)
网络环境：TCP/IP 协议
所需端口：3001（默认，可修改）
无其他依赖（自包含发布，内置.NET运行时）

四、防火墙设置

如需局域网访问，在服务器端防火墙放行端口：
  Windows Defender 防火墙 → 高级设置 →
  入站规则 → 新建规则 → 端口 → TCP → 3001
